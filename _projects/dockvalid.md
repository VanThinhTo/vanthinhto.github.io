DockValid streamlines docking post-processing for retrospective studies. It was
built to reduce manual work when comparing docking outputs and validating
screening performance across software packages.

It provides:

- Automated extraction of docking results.
- Retrospective-control workflows for docking evaluation.
- A reusable base for model selection in virtual screening campaigns.
